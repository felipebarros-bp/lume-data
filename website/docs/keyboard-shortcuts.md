# Keyboard shortcuts

On Windows and Linux, **Cmd** is **Ctrl** and **Option** is **Alt**. The menus and the [command palette](workspace/navigation.md) show each shortcut as your system writes it. Panel and window shortcuts can be [changed](workspace/navigation.md#custom-shortcuts).

## Files, connections and tabs

| Action | macOS | Windows / Linux |
|---|---|---|
| New query tab (**File > New SQL Tab**) | Cmd+T | Ctrl+T |
| New Query | Cmd+N | Ctrl+N |
| Open... | Cmd+O | Ctrl+O |
| Quick Open... | Cmd+P | Ctrl+P |
| Save (file tab) | Cmd+S | Ctrl+S |
| New Connection... | Shift+Cmd+N | Shift+Ctrl+N |
| Edit Connection... | Cmd+E | Ctrl+E |
| Connect / Disconnect | Cmd+D | Ctrl+D |
| Switch Tab... | Ctrl+Tab | Ctrl+Tab |
| Settings... | Cmd+, | Ctrl+, |
| Quit Lume | Cmd+Q | Ctrl+Q |

## Editing

| Action | macOS | Windows / Linux |
|---|---|---|
| Undo / Redo | Cmd+Z / Shift+Cmd+Z | Ctrl+Z / Shift+Ctrl+Z |
| Cut / Copy / Paste / Select All | Cmd+X / C / V / A | Ctrl+X / C / V / A |
| Complete | Ctrl+Space | Ctrl+Space |
| Ask Lume Intelligence about the query tab | Cmd+K | Ctrl+K |

## Running SQL

| Action | macOS | Windows / Linux |
|---|---|---|
| Run Statement | Cmd+Return | Ctrl+Enter |
| Run All | Shift+Cmd+Return | Shift+Ctrl+Enter |
| Run in New Tab | Option+Cmd+Return | Alt+Ctrl+Enter |
| Explain Plan | Option+Cmd+E | Alt+Ctrl+E |
| Cancel Execution | Cmd+. | Ctrl+. |
| Show Execution Output | Shift+Cmd+O | Shift+Ctrl+O |
| Execution History... | Cmd+Y | Ctrl+Y |

| Action | macOS | Windows / Linux |
|---|---|---|
| Find in Results | Cmd+F | Ctrl+F |
| Export Results... | Shift+Cmd+E | Shift+Ctrl+E |
| Fetch More Rows | Shift+Cmd+M | Shift+Ctrl+M |
| Columns... | Shift+Cmd+C | Shift+Ctrl+C |
| Next / Previous Result Tab | Option+Cmd+] / Option+Cmd+[ | Alt+Ctrl+] / Alt+Ctrl+[ |
| Close Result Tab | Cmd+W | Ctrl+W |
| Edit cell | Enter or F2 | Enter or F2 |

## Output panel

| Action | Keys |
|---|---|
| Search | Cmd+F |
| Next / previous match | Enter / Shift+Enter in the field; Cmd+G / Shift+Cmd+G or F3 in the list |
| Copy messages / details | Cmd+C / Shift+Cmd+C |

## Object editor

| Action | Keys |
|---|---|
| Go to Definition | F12 |
| Next / previous problem | F8 / Shift+F8 |

## ER diagrams

| Action | macOS |
|---|---|
| Find | Cmd+F, then Enter / Shift+Enter (or F3 / Shift+F3) |
| Fit / Fit Selection | Cmd+1 / Cmd+2 |
| Zoom in / out / 100 % | Cmd+= / Cmd+- / Cmd+0 |
| Back / Forward | Cmd+[ / Cmd+] |
| Auto layout | Shift+Cmd+L |
| Copy as Image | Shift+Cmd+C |
| Undo / Redo a move | Cmd+Z / Shift+Cmd+Z |
| Move between cards | arrow keys, Tab / Shift+Tab |
| Remove from the diagram | Delete |

Inside a diagram or report tab, these take precedence over the global shortcuts with the same keys.

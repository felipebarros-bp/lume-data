# Lume Data

Lume Data is a fast, lightweight, native database IDE. It is written in C on SDL3, so it starts quickly, stays at 0 % CPU while idle and remains responsive on catalogs with tens of thousands of tables.

## Databases

| Database | Connect | Browse & edit objects | Table designer | ER diagrams | Execution plans |
|---|---|---|---|---|---|
| SQLite | yes | yes | yes | yes | yes |
| PostgreSQL | yes | yes | yes | yes | yes |
| MySQL / MariaDB | yes | yes | yes | yes | yes |
| SQL Server | yes | yes | yes | yes | yes |
| Oracle | yes | yes | yes | yes | yes |

## What is in it

- **SQL editor** with completion that knows your schema, including whole `JOIN ... ON` conditions from foreign keys.
- **Result grid** that streams large results, with filtering, sorting and export.
- **Schema Explorer** built for servers with thousands of schemas.
- **Object editor** and **Table Designer**: every change is reviewed as SQL before it runs.
- **[ER diagrams](explore/er-diagrams.md)** of real foreign keys, for databases of any size.
- **Execution plans**, **Report Studio** and **Source Control**.
- **Lume Intelligence**, an optional AI assistant that only sees what you consent to.

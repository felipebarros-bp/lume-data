# A five-minute tour

- **Run SQL**: type a statement and press **Cmd+Return** (Ctrl+Enter on Windows / Linux) to run the statement under the caret.
- **Command palette**: **Shift+Cmd+P** (Shift+Ctrl+P) finds any action by name.
- **Explorer**: double-click a table to preview its rows; right-click it for its menu (Edit Data, Modify Table..., Show ER Diagram...).
- **Completion**: after `JOIN orders o ON`, Lume proposes the join conditions from the foreign keys, every column of a composite key included.
- **Settings**: **Cmd+,** (Ctrl+,).
